이 폴더 안의 파일을 그대로 웹사이트에 게시하면 됩니다.
별도 설치·빌드·외부 라이브러리·유료 API가 필요 없는 정적 웹사이트입니다.
공식 기출 2,980문항과 창작 예상문제 750문항, 총 3,730문항을 제공합니다.
원문 이미지 413장은 필요한 문제를 열 때 불러옵니다.
기존 단일 index.html은 원래 위치에 그대로 보관했습니다.

1. GitHub Desktop으로 올리기

이미 trainer-exam 저장소를 만들었다면, 이 폴더의 '내용물' 전체를
저장소 폴더 안에 복사하세요. 저장소 바로 아래에 index.html이 있어야 합니다.

저장소를 아직 만들지 않았다면 GitHub Desktop의 File → New Repository에서
Name을 trainer-exam, Local path를 이 폴더의 부모 폴더로 선택하세요.
README·Git ignore·License는 추가하지 않고 Create repository를 누르면
이 폴더를 저장소로 관리할 수 있습니다. 별도 위치에 저장소를 만든 뒤
이 폴더 내용물을 복사해도 됩니다.

GitHub Desktop에서 변경 파일을 확인하고 Summary에 '문제은행 게시용 등록'을
입력한 뒤 Commit to main을 누르세요. Publish repository를 누르고,
무료 GitHub Pages를 사용할 경우 Keep this code private 체크를 해제하세요.
공개 저장소에는 업로드한 코드와 문제 자료도 공개됩니다.

2. 사이트 주소 만들기

GitHub의 해당 저장소 → Settings → Pages에서 다음을 선택하세요.
Source: Deploy from a branch
Branch: main (다른 기본 브랜치를 사용한다면 실제 브랜치 선택)
Folder: / (root)
Save를 누르고 게시가 끝나면 Visit site로 열 수 있습니다.
주소 형식: https://사용자이름.github.io/trainer-exam/

중요: 이 폴더 내용물 전체를 올리세요. index.html만 올리거나 ZIP 파일만
올리면 작동하지 않습니다. 기존 104MiB 오프라인 index.html, PDF 원본,
개인 학습 기록 백업, question-bank 작업 폴더는 게시에 필요하지 않습니다.
이미지가 많으므로 브라우저 업로드보다 GitHub Desktop 사용이 편합니다.
.nojekyll 파일은 일반 정적 파일로 게시하기 위한 빈 파일입니다.

data/sports.json         생활스포츠지도사 2급 1,890문항 (기출 1,540 + 창작 350)

images/                 원문 이미지 413장

모든 주소는 상대 경로라 저장소 이름이나 사용자 이름이 바뀌어도 사용할 수
있습니다. 기존 문제·정답·출처·사이트 이름을 유지했습니다.
시험 안내의 확인일은 원본에 있는 날짜를 유지했습니다.

방문자가 사이트의 '문제 불러오기'로 추가한 문제는 해당 브라우저에만
저장됩니다. 모든 방문자에게 문제를 추가하려면 해당 시험 JSON 배열에
문제를 넣어 저장소를 업데이트하세요. 예시 형식은 사이트의
문제 데이터 → 예시 JSON 내려받기로 받을 수 있습니다.
문제 ID는 중복되면 안 됩니다. 원문 이미지가 있는 새 문제는 images에
파일을 넣고 page-assets.json에 './images/파일명.webp'를 연결하세요.

수정 후 GitHub Desktop에서 Commit to main → Push origin을 누르면
GitHub Pages가 변경 내용을 반영합니다.

4. 학습 기록 옮기기

기존 오프라인 파일에서 문제 데이터 → 학습 기록 백업을 누르세요.
게시한 사이트에서 문제 데이터 → 학습 기록 복원으로 백업을 선택하세요.
오답·북마크·메모·완료한 학습 기록을 가져올 수 있습니다.
복원 시 진행 중이던 풀이는 종료되며 기존 웹사이트 기록을 대체합니다.
직접 추가한 문제가 있다면 해당 문제 JSON을 먼저 불러오세요.
기록은 기기·브라우저·사이트 주소별로 저장되며 자동 동기화되지 않습니다.

5. 미리보기와 인터넷 연결

이 웹 게시용 index.html을 더블클릭하면 실행 방법 안내가 나옵니다.
문제 JSON을 불러오므로 HTTP/HTTPS 주소에서 실행해야 합니다.
인터넷 없이 파일을 더블클릭해서 사용하려면 원래의 단일 HTML을 쓰세요.

개발용 로컬 미리보기 (Python 3이 설치되어 있는 경우):
이 폴더를 터미널에서 연 뒤 python3 -m http.server 8765 --bind 127.0.0.1
브라우저에서 http://127.0.0.1:8765/ 접속. 종료는 Ctrl+C.

첫 화면에서는 문제 텍스트와 설정만 읽습니다. 각 원문 이미지는 해당 문제를
열 때 불러오며, 전체 이미지를 미리 다운로드하지 않습니다.
완전한 오프라인 웹 앱이나 로그인·기기 간 동기화 기능은 추가하지 않았습니다.
문제 JSON 내보내기에는 호환성을 위해 원문 이미지를 모두 포함하므로
100MiB가 넘는 파일이 생성됩니다. 내보내는 동안 인터넷 연결이 필요합니다.

공식 안내:

6. 추가된 해설 기능

연습에서는 ‘정답·해설 확인’을 누르면 정답 근거, 선택지별 설명,
기억할 핵심과 참고 자료를 볼 수 있습니다. 모의고사에서는 제출 후
결과 화면의 ‘전체 문제·해설 보기’로 확인합니다.
작성 해설은 공식 해설이 아닌 AI 초안이며, 검토가 필요한 문항은 별도로
표시합니다. 공식 정답표와 충돌할 가능성이 있는 문항도 정답표의 채점
번호를 자동으로 바꾸지 않습니다. 공식 정답 미확인 문항의 추정 정답은
채점에 사용하지 않습니다.

현재 작성·검토 필요·미작성 수는 사이트의 ‘문제 데이터’에서 확인하세요.
웹 버전은 해설을 볼 때 해당 시험·연도 파일을 불러옵니다.
단일 오프라인 index.html에는 작성된 해설이 직접 들어 있습니다.
문제 JSON 내보내기는 해설 본문·참고 자료·검토 상태도 함께 보관합니다.
웹에 업데이트할 때는 js, css, data/explanations를 포함한 폴더 전체를
다시 업로드하세요. 기존 학습 기록을 초기화할 필요는 없습니다.

7. 과목별 창작 예상문제 (2026-11-16 추가)

건강운동관리사 8과목 × 50문항 = 400문항
생활스포츠지도사 2급 7과목 × 50문항 = 350문항
기존 창작 예시 20문항의 ID와 내용을 유지하고 730문항을 보충했습니다.
모든 창작 문항은 정답 근거와 보기 4개의 해설을 포함합니다.
‘정답·해설 확인’을 누르면 정답 번호·보기 내용·정답의 이유를 담은
‘정답 해설’ 영역으로 이동합니다. 오답을 골랐어도 올바른 답의 이유를
확인할 수 있으며, 모의고사에서는 제출 후 해설을 볼 수 있습니다.
학습용 창작 예상문제이며 실제 기출문제가 아닙니다.

이용 방법: 시험 선택 → 문제 종류 '창작 예시' → 과목 선택 → 학습 시작.
과목의 50문항을 한 번에 풀려면 문제 수를 '50문항'으로 선택하세요.
무작위 연습과 정규 구성 모의고사에서도 창작 예시를 사용할 수 있습니다.
건강운동관리사 160문항, 생활스포츠지도사 2급 선택 5과목 100문항을
중복 없이 구성하며 모의고사 해설은 제출 후 표시됩니다.

기존 기출·기출 해설·학습 기록은 유지됩니다.
문항은 학습용 작성 자료이며 공식 출제 기관의 검수·인증을 받은 자료가 아닙니다.

8. 난이도별 학습 (2026-11-23 추가)

기출 2,980문항과 창작 예시 750문항을 실제 문제 내용에 따라 다시 검토해
하·중·상으로 분류했습니다. AI의 내용 검토에 따른 사이트 자체 예상
난이도이며, 공식 출제기관의 평가나 이용자 첫 풀이 정답률이 아닙니다.

하: 기본 개념 하나를 알고 직접 답할 수 있는 문제
중: 관련 개념을 구별하거나 원리·공식을 한두 단계 적용하는 문제
상: 여러 조건·개념·자료를 연결하거나 여러 단계의 계산이 필요한 문제

긴 지문, 부정형 질문, 생소한 용어, 그림의 존재만으로 높게 분류하지
않았습니다. 쉬운 문항을 억지로 상으로 배정하지 않으므로, 특정 과목이나
창작 예시에서 상 문항이 없을 수 있습니다.

사용 순서: 시험 → 학습 방식 → 과목·연도·문제 종류 → 난이도 → 학습 시작.
난이도 버튼에 현재 선택 조건의 문항 수를 표시합니다. 부족한 문항은
중복해서 채우지 않으며, 0문항이면 조건 변경 안내를 표시합니다.
오답노트에서는 ‘필터’에서 난이도를 고르고 상단 복습 버튼을 누릅니다.
북마크에서는 난이도를 고르고 ‘모아서 풀기’를 누릅니다.
선택한 연습 난이도는 시험별로 이 브라우저에 저장합니다.
모의고사는 시험 구성과 문항 수를 유지하도록 전체 난이도에서 출제합니다.

문제 상단에서 난이도를 확인하고, 채점 후 해설의 ‘난이도 평가 근거’를
열면 판단 이유·문제 유형·검토일을 볼 수 있습니다. 문제 유형은 개념 암기,
원리 이해, 계산, 자료 해석, 사례 적용이며 난이도와 따로 관리합니다.

문제 JSON의 difficulty 값은 하/중/상, 미평가 문제는 미분류입니다.
기존 기초/중급/응용 값은 가져올 때 하/중/상으로 변환하며 그 밖의 기존
값은 미분류로 표시합니다. difficultyReview(판단 근거·검토일)와
questionTypes(문제 유형)도 내보내기·가져오기에서 유지됩니다.
기존 문제 ID와 정답·해설은 유지하므로 오답·북마크를 초기화할 필요가 없습니다.

- 관리자 문항 통계: admin.html

오답노트 개선 (2026-11-23, 미니멀 화면)
- ‘다시 풀기 / 완료 / 전체’ 세 탭으로 정리했습니다. 다시 풀기와 완료는 서로 겹치지 않으며 합계가 전체 이력 수와 같습니다.
- 상단 복습 버튼 하나로 현재 조건에 맞는 5문항부터 시작합니다. 미해결 문제 중 반복 오답을 먼저, 그 뒤 3일 이상 지난 복습 완료 문제를 추천합니다.
- 과목과 문제·메모 검색은 바로 보입니다. ‘필터’를 펼치면 난이도, 정렬, 5/10/20/전체 문항 수, 2회 이상 오답 조건을 설정할 수 있습니다.
- ‘문제 선택’을 누르면 체크박스가 나타납니다. 여러 페이지에서 고른 문제 또는 검색 결과 전체를 선택해 상단 복습 버튼으로 풀 수 있습니다.
- ‘해설·메모’에서 마지막으로 틀린 선택 답안과 해설을 확인하고, 오답 이유와 기억할 핵심을 자동 저장합니다.
- 오답 이유는 기존 학습 메모에 읽을 수 있는 한 줄로 함께 보관합니다. 기존 메모·백업·로그인 계정의 메모 동기화 형식을 유지합니다.
- 정답 확인이나 제출로 다시 맞힌 경우에만 복습 완료 처리합니다. 해설 열람만으로 완료 처리하지 않습니다. 이전 오답 횟수는 삭제하지 않습니다.
- 3일은 사이트의 고정된 복습 권장 간격이며, 기기 날짜 기준입니다. 숙달 판정이나 푸시 알림이 아닙니다. 이전 기록에 선택 답안이 없으면 추정하지 않습니다.
- 검증: 추천/필터/중복 없는 상태 탭/3일 재점검/서버 판정 우선/모의고사 답안 비공개 단위 검사; 별도 테스트 기록으로 선택 복습→채점→완료 이동, 이유·메모 저장, 새로고침 유지, 시험 분리, 빈 화면 안내, 여러 페이지 선택, 키보드 선택, 390px/320px 화면 넘침 검사.
- 실제 다른 기기 간 계정 동기화는 로그인·이메일 발송 설정 완료 후 추가 검증이 필요합니다. 이 개선에서 메일 설정을 변경하지 않았습니다.
