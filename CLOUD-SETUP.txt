트레이너 자격증 문제은행 · Supabase 운영 안내
기준일: 2026-11-23

1. 현재 연결
- 사이트: https://withkyobody-kyo.github.io/trainer-exam/
- 관리자 통계: https://withkyobody-kyo.github.io/trainer-exam/admin.html
- 프로젝트: Kyobody / trainer-exam / 서울 / Free
- 프로젝트 주소: https://supabase.com/dashboard/project/hhflqeqmlmwhynififwb
- 비밀번호나 service_role 키는 공개 사이트에 넣지 않습니다. cloud-config.js에는 공개용 publishable key만 있습니다.

2. 프로젝트를 새로 구성하는 순서
- Supabase 가입/로그인 → 조직과 무료 프로젝트 생성 → 서울 지역 선택.
- SQL Editor에서 supabase 폴더의 001~004 SQL을 번호 순서대로 실행.
- 002는 현재 3,730문항의 서버 기준 정답표입니다. 문제 ID/정답을 바꿀 때에는 클라이언트와 서버 기준표를 함께 검토해야 합니다.
- Authentication → Sign In / Providers → Email 활성화 및 이메일 인증 유지.
- Authentication → URL Configuration → Site URL과 Redirect URLs 모두 https://withkyobody-kyo.github.io/trainer-exam/ 으로 등록. 불필요한 와일드카드는 추가하지 않습니다.
- js/cloud-config.js에 프로젝트 URL과 publishable key 입력. secret/service_role 키를 넣지 않습니다.

3. 현재 Gmail을 이용한 메일 발송
- withkyobody@gmail.com의 Google 계정에서 2단계 인증을 켭니다.
- https://myaccount.google.com/apppasswords 에서 앱 비밀번호를 생성합니다.
- Supabase Authentication → Emails → SMTP Settings:
  Enable custom SMTP: 켬
  Sender email: withkyobody@gmail.com
  Sender name: 트레이너 자격증 문제 은행집
  Host: smtp.gmail.com
  Port: 465
  Username: withkyobody@gmail.com
  Password: Google에서 만든 앱 비밀번호(일반 Google 비밀번호 아님)
- 비밀번호는 사용자가 직접 입력하고 Save changes를 누릅니다. 채팅/코드/저장소에 보내지 않습니다.
- 앱 비밀번호 메뉴는 Google 계정 보호 방식·조직 정책에 따라 없을 수 있습니다.
- Gmail은 소규모 시작용입니다. Supabase 화면에서도 개인 메일용 서버의 도달률 경고가 표시됩니다. 대규모 서비스에는 소유 도메인과 인증된 전용 발송 서비스를 권장합니다.
- Supabase 기본 발송은 조직 팀 주소에 제한되고 시간당 2통입니다. custom SMTP는 초기 시간당 30통 제한입니다. Gmail의 개인 발송 한도/스팸 방지 제한도 따로 적용됩니다.

4. 실제 동작을 확인하고 일반 가입 공개
- 사이트의 로그인 · 동기화 → 회원가입에서 withkyobody@gmail.com으로 가입합니다.
- 받은 메일의 링크를 눌러 인증한 뒤 로그인합니다.
- SQL Editor에서 005_register_admin.sql을 실행합니다. 이메일 인증된 실제 사용자 UUID를 서버의 관리자 목록에 등록합니다.
- 새로운 문제를 풀고 상단 ‘서버 저장 완료’를 확인합니다.
- 휴대폰에서 같은 계정으로 로그인하여 기록/북마크/메모/진행 중인 학습을 확인합니다.
- 비밀번호 찾기로 재설정 메일을 받고 링크에서 새 비밀번호를 설정합니다.
- 위 메일 발송 테스트를 확인한 다음 cloud-config.js의 publicSignupReady를 true로 바꾸고 게시합니다.
- 현재 이 값이 false이면 일반 가입은 준비 중으로 표시하고 운영자 주소의 가입만 허용합니다. 이 표시는 공개 전 운영상의 안내이며 접근제어 수단이 아닙니다.

5. 기록 및 충돌 처리
- 비로그인 기록 motionnote.study.v1은 그대로 유지합니다.
- 로그인 기록과 전송 대기열은 사용자 UUID별로 구분합니다. 자동으로 다른 계정에 가져오지 않습니다.
- 계정 메뉴의 ‘기존 브라우저 기록 옮기기’를 직접 선택해야 가져옵니다. 원본을 지우지 않습니다.
- 기존 누적 풀이 수는 같은 문항의 더 큰 가져오기 값으로 병합하므로 재전송을 더하지 않습니다. 계정에 이미 있는 메모·북마크·같은 학습 내역은 우선 보존합니다.
- 기존 연습과 1교시 진행 기록은 이어풀기를 옮깁니다. 가져오는 시점에 이미 2교시/휴식 중이던 기존 모의고사는 개인 학습 내역으로 보관하며 새 제한시간을 부여하지 않습니다.
- 같은 세션/문항의 응답은 1회 저장합니다. 새로 시작한 세션은 별도 풀이입니다.
- 인터넷이 끊기면 이 기기에 대기열을 남기고 연결 복구 시 전송합니다. 원문 이미지/해설까지 완전한 오프라인 제공을 보장하지는 않습니다.
- 서버의 변경 번호와 일치할 때만 메모·북마크·세션을 저장합니다. 두 기기에서 충돌하면 자동 덮어쓰기 없이 계정 메뉴에서 한쪽을 선택합니다. 해결 전 동기화가 대기합니다. 양쪽 내용의 백업을 이 기기에 보존합니다.
- 동일 브라우저의 여러 탭에서 계정을 함께 수정하면 오래된 탭을 잠그고 새로고침을 안내합니다.
- 모의고사의 절대 종료시각은 서버에 고정합니다. 새로고침/다른 기기에서 시간이 늘어나지 않습니다. 서버 시각을 지난 응답은 난이도 통계에서 제외됩니다.
- 학습 기록 초기화는 확인 후 해당 시험의 서버 기록도 삭제합니다. 두 기기에 전송 대기가 있다면 먼저 동기화하는 것이 좋습니다. 집계도 삭제한 기록에 맞춰 달라집니다.
- 직접 JSON으로 추가한 문제는 해당 기기에 남으며 현재 서버 기준표/통계/동기화 대상에서 제외됩니다.

6. 문항 통계
- 정답 판단은 서버 catalog의 정답 배열을 사용합니다. 복수 인정 정답을 지원합니다.
- 정답 미확인 140문항과 미응답은 오답으로 처리하지 않습니다.
- 첫 풀이: 과거 가져오기/응답/해설 열람 이력이 없고 온라인으로 서버가 인정한 계정별 첫 응답 1개.
- 반복 또는 열람 후의 응답은 첫 풀이와 분리합니다.
- 기존 기록과 오프라인/지연 응답은 개인 이력에 저장하지만 난이도 통계에 포함하지 않습니다.
- 통계는 기본 50명 미만에 ‘통계 부족’을 표시합니다. 관리자가 5~10,000명 범위에서 수정할 수 있습니다.
- 내용 기준 하·중·상 난이도는 자동 변경하지 않습니다.
- 공개 사이트의 JSON에는 정답이 들어 있어 정답을 미리 검색하는 행위를 완벽히 막을 수는 없습니다. 첫 풀이 통계는 서버에서 관측 가능한 계정 이력 기준이며 감독시험 데이터가 아닙니다. 시간은 브라우저가 보고한 활성 풀이 시간입니다.

7. 무료 플랜과 비용
공식 요금표 확인: https://supabase.com/pricing
Free: DB 500MB/프로젝트, 파일 저장 1GB, 월 활성 사용자 50,000명,
일반 전송량 5GB + 캐시 전송량 5GB, 활성 프로젝트 2개.
Free 프로젝트는 1주 비활동 시 일시 중지될 수 있습니다. 무료에는 무제한 저장/발송/상시 가동 보장이 없습니다.
문제 풀이가 쌓이면 DB 용량과 전송량을 Usage에서 확인하세요. 이 사이트의 원문 이미지는 GitHub Pages에서 제공하며 Supabase Storage는 사용하지 않습니다.
현재 유료 플랜/추가 옵션을 구매하지 않았습니다. Pro는 월 $25부터이며 추가 컴퓨트/사용량/선택 기능에 비용이 생길 수 있습니다. 업그레이드 전 화면의 요금과 Spend Cap 조건을 확인하세요.
Google 및 별도 SMTP 서비스의 한도/요금은 Supabase와 별개입니다.
