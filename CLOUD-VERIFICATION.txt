아직 완료로 판단하지 않는 항목
- 실제 회원가입 → 인증 메일 수신 → 이메일 인증 → 로그인
- 실제 비밀번호 재설정 메일 수신/새 비밀번호 로그인
- 실제 PC/휴대폰 두 기기의 동일 계정 동기화와 이어풀기
- 운영자 계정의 이메일 인증 후 서버 관리자 등록 및 실제 통계 화면 조회
- 다른 일반 회원 주소로 메일을 수신하는 공개 가입 검증
위 항목을 확인하기 전 일반 가입은 publicSignupReady=false로 표시합니다.

남은 제약

- 원문 이미지/해설의 완전한 오프라인 제공은 이번 변경 범위에 포함하지 않았습니다.
- 기존 로컬 모의고사의 휴식/2교시 중간 기록 가져오기는 완료 이력으로 보존합니다.
- 공개 정답을 미리 조회한 행동과 실제 인간의 풀이 시간까지 서버가 증명할 수는 없습니다.
- SMTP와 무료 플랜 사용량/일시 중지는 운영자가 확인해야 합니다.
