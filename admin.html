QUESTION INSIGHTS

운영자 문항 통계

내용 기준 난이도와 실제 응답 결과를 구분해 확인하세요.

학습실로

통계에는 서버 정답표로 채점한 유효 응답만 사용합니다. 한 사람의 첫 유효 응답은 한 번만 반영하며, 기존 기록·오프라인 재전송·미응답·정답 미확인은 제외합니다. 정답 공개 후의 응답과 반복 풀이는 별도 집계합니다.

로그인 후 관리자 권한을 확인합니다.

정답률이 낮은 순서입니다. ‘통계 부족’ 문항의 수치는 참고용입니다. 기존 하·중·상 난이도를 자동 변경하지 않습니다. 선택지 비율은 첫 유효 응답자 기준이며, 시간 중앙값은 사용 기기가 보고한 활성 풀이 시간(0초 제외)을 기준으로 합니다.

통계 해석의 한계

이 서비스는 학습 도구입니다. 공개된 문제 데이터에서 정답을 미리 찾아보는 행위를 기술적으로 차단하지는 못합니다. ‘첫 풀이’는 이 계정에서 서버가 처음 인정한 응답을 뜻합니다. 네트워크가 끊긴 동안의 제출 순서나 실제 학습 시간을 서버가 입증할 수 없어 해당 응답은 난이도 통계에서 제외합니다.
